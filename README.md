# Basics of Web Testing with Playwright

👋 Welcome!

It's great to have you here. I'm sure you will love this course. ❤️

## What will you learn?

By taking the Basics of Web Testing with Playwright course, you will learn:

- How to install and configure Playwright for web testing
- How to set up a Playwright project from scratch
- How to navigate to web pages
- How to locate elements with user-facing locators (by label and by role)
- How to fill in form fields
- How to click buttons
- How to write web-first assertions that automatically wait and retry
- How to write a happy-path test that fills out a form, submits it, and checks the success message
- How to write non-happy-path tests for missing mandatory fields
- How to write non-happy-path tests for an invalid email format
- How to assert on error messages
- How to run your tests in headless mode
- How to run your tests in headed mode
- How to run your tests in the interactive UI Mode
- How to debug failures using the Trace Viewer
- How to run your Playwright web tests on GitHub Actions
- How to use Playwright's MCP in the context of web testing
